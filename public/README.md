# Drop real photos here
- `gallery-1.jpg` … `gallery-6.jpg` — the transformation gallery (download the originals from the GoDaddy builder; they belong to the business)
- Put other site images in `public/images/` (e.g. `about.jpg`, referenced in `lib/site.js`)
Files in this folder are served at the root of the site, e.g. `public/gallery/gallery-1.jpg` → `/gallery/gallery-1.jpg`.
